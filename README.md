## Getting Started (Local Setup)

```bash
# 1. Clone the repository
git clone https://github.com/your-username/netclixcloud-website.git

# 2. Navigate into the project
cd netclixcloud-website

# 3. Set up environment variables
cp .env.example .env
# Fill in your actual values in .env (DO NOT commit .env to GitHub)

# 4. Deploy to Apache Tomcat for JSP pages
# OR open index.html directly in browser for static pages
```

---

## Environment Variables

Create a `.env` file in the root directory by copying `.env.example`:

```
DB_HOST=your_database_host
DB_USER=your_database_user
DB_PASS=your_database_password

SMTP_HOST=your_smtp_host
SMTP_USER=your_email
SMTP_PASS=your_email_password

EMAIL_API_KEY=your_bulk_email_api_key
WEBHOOK_SECRET=your_webhook_secret

GA_TRACKING_ID=your_ga_id
```

NEVER commit your .env file to GitHub. It is already listed in .gitignore.
